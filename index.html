          Chaves de acesso (opcional)

          Para usar os mesmos dados 3D fotorrealistas do Google Earth, informe uma chave da Google Maps Platform (Map Tiles API). Um token do Cesium ion habilita terreno mundial de alta precisão e prédios OSM 3D. As chaves ficam salvas apenas no seu navegador.

          Desempenho

          Navegação

          • Arrastar: mover o globo
          • Roda do mouse: zoom
          • Ctrl + arrastar / botão direito: inclinar e girar
          • Duplo clique: aproximar do ponto
          • Clique: ver informações do local (Wikipedia, coordenadas, Street View)

          Atalhos

          • / pesquisar
          • N apontar para o norte · U vista de cima
          • R redefinir vista · +/- zoom
          • F modo voo (W/S acelera, A/D gira, Q/E sobe/desce, setas olham)
          • M medir · Esc cancelar ferramenta

          Fontes de dados

          Imagens: Esri World Imagery, NASA GIBS, OpenStreetMap, OpenTopoMap. Relevo: Esri World Elevation. Pesquisa: OpenStreetMap Nominatim. Conhecimento: Wikipedia. 3D fotorrealista: Google Map Tiles API (com chave).
